# Sistema de Gestión de Emergencias Médicas

Simulación en Java de un centro de emergencias médicas. Las llamadas llegan en cualquier momento y el sistema asigna ambulancias, médicos y equipos según la urgencia de cada caso. Todo funciona con hilos (programación concurrente) y se muestra en la consola en tiempo real.

Proyecto de IU Digital de Antioquia.
